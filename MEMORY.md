# agents-helmfile memory

Lessons that outlive a session. Newest first.

- 2026-10-24: **agent-orchestrator moved to `lab.szymonrichert.pl` behind the cluster's oauth2-proxy admission webhook** (pod annotations, same as the infrastructure helmfile's searxng/comfyui). Three non-obvious consequences: (1) the annotations sit under `components.api.podAnnotations` (chart support added in agent-orchestrator PR #6): the cluster's webhook is the Go injector (infrastructure `containers/apps/oauth2proxy-injector`, not the older python oauth2-proxy-admission-controller repo), which rejects annotated pods whose first container has no ports and has no `patch-container-name`; a global podAnnotations apply failed and rolled back on 2026-10-24; (2) the api now sees every browser request from 127.0.0.1 (the sidecar), so `ORCH_ALLOWED_CIDRS` is `127.0.0.1/32` and the old node pod-gateway /31s are gone - the ingress no longer reaches port 8000 directly; (3) the public host needs SSO, so `scripts/smoke.sh` port-forwards to the api by default (a port-forward also arrives from 127.0.0.1). Probes target 8000 by number because the webhook hands the name `http` to its sidecar. The `agent-orchestrator-proxy` Secret comes from the infrastructure repo's `terraform/keycloak` (`agents` block).
