# agents-helmfile memory

Lessons that outlive a session. Newest first.

- 2026-10-25: **hive release applied live** (helm revision 9, then the wrapper pin fix): chart `0.1.0-main.a5b5a75`, orchestrator image `a5b5a75`, wrapper image `harbor.szymonrichert.pl/containers/claude-code-wrapper:0.2.0` (digest `sha256:fad6a4c2978a63facf21456bda89b64efa90303bf54495c51c867761c4ffa33a`, built from wrapper commit 1f64e9f), `ORCH_ANY_MCP_REF` `v0.2.0`. The wrapper is pinned by release tag because Harbor prunes the wrapper's sha7 tags: the first apply with `:1f64e9f` left every agent pod in ImagePullBackOff (`not found`). `mise run smoke` now creates its own 2-replica hive, waits for a leader and calls `/agent/v1/me` from the agent pod through the agents Service: 200, so the lab CNI keeps the pod source IP through the Service and the pod-IP binding of the agent token holds. The LAN-only ingress whitelist is gone (PR #12); the node-IP denylist stays.
- 2026-10-24: **agent-orchestrator moved to `lab.szymonrichert.pl` behind the cluster's oauth2-proxy admission webhook** (pod annotations, same as the infrastructure helmfile's searxng/comfyui). Three non-obvious consequences: (1) the annotations sit under `components.api.podAnnotations` (chart support added in agent-orchestrator PR #6): the cluster's webhook is the Go injector (infrastructure `containers/apps/oauth2proxy-injector`, not the older python oauth2-proxy-admission-controller repo), which rejects annotated pods whose first container has no ports and has no `patch-container-name`; a global podAnnotations apply failed and rolled back on 2026-10-24; (2) the api now sees every browser request from 127.0.0.1 (the sidecar), so `ORCH_ALLOWED_CIDRS` is `127.0.0.1/32` and the old node pod-gateway /31s are gone - the ingress no longer reaches port 8000 directly; (3) the public host needs SSO, so `scripts/smoke.sh` port-forwards to the api by default (a port-forward also arrives from 127.0.0.1). Probes target 8000 by number because the webhook hands the name `http` to its sidecar. The `agent-orchestrator-proxy` Secret comes from the infrastructure repo's `terraform/keycloak` (`agents` block).
- 2026-10-25: **the LAN-only ingress allowlist (`allowSourceRanges` 192.168.1.0/24) is removed.** It was a stopgap until the oauth2-proxy sidecar landed (2026-10-24 entry above); with SSO in front of the api it only blocked legitimate access from outside the LAN, including requests arriving through Cloudflare. The node-IP `denySourceRanges` stays: agent pods egress SNATed to node IPs must not reach the browser API through the ingress.
- 2026-10-25: **init scripts release applied live** (helm revision 11): chart `0.1.0-main.22cf283`, orchestrator image `22cf283` (agent-orchestrator PR #10). The pre-apply diff changed only the chart version, image tag and derived labels/settings checksum; the post-apply diff shows no affected releases. `mise run smoke` ended with "smoke: OK" on its 2-replica hive with `init_scripts: ["echo smoke-init"]`: init scripts state succeeded, log tail contains smoke-init, leader elected, `/agent/v1/me` 200.
